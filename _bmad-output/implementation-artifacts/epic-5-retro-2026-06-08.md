## What could be better

1. **The same React `useCallback` stale-closure bug shipped TWICE (5.2 `currentDepth`, 5.4 `motionAllowed`)** — each disabling a load-bearing behavior on the real path behind a green gate, because the e2e asserted the *off* case (vacuously passing) rather than the *on* case. The 5.4 occurrence even sat directly below the 5.2 fix's comment. → **Rule 12** (every captured reactive value in the deps; assert the gated behavior IS applied on the real path; heed `react-hooks/exhaustive-deps`).
2. **"Attribute set, but no consumer" visual no-ops (5.4 deepen).** `data-depth="deep"` was set on a section but no CSS consumed it, so deepened scenes showed nothing — and the test asserted the attribute, not the rendered outcome. → **Rule 13** (assert the user-observable result + verify the consumer, not just the signal).
3. **New build-graph shapes re-open NFR-6.** Story 5.1's first-ever dynamic `import()` chunks introduced Rollup hash nondeterminism (intermittent `check-deterministic` failure), fixed with vendor `manualChunks`. A reminder that NFR-6 must be re-checked whenever the bundling topology changes (first dynamic import, first worker, first wasm asset).
4. **Agent-feature LLM latency is a live-config concern (NFR-4).** gpt-5-mini's reasoning-class tail latency (~16.5s streaming, measured) exceeded the `/api/guide` 15s ceiling live and tripped the graceful fallback. Resolved by switching the Guide to claude-haiku-4-5 (~2-3s) and making it the committed default. The 5.3 re-curation also adds a second LLM call per grounded turn — keep an eye on cumulative latency (deferred-work).
