## What could be better

1. **The `format:check` launch-gate gap.** Per-story verification ran *scoped* prettier checks (`prettier --check "src/**" …`), not the ROOT `pnpm format:check` (`prettier --check .`, which formats `.astro` via the plugin). So format-RED `.astro` files shipped in 2.2 & 2.3 and the `test:all` launch gate was silently broken from 2.2 until the lead caught it at 2.4. → **Rule 5.** (After the fix, 2.5/2.6 ran the root gate and stayed green — the correction propagated.)
2. **Doc-accuracy is invisible to mechanism tests.** 2.6's import doc was wrong about a user-observable outcome even though the render mechanism was right; only a literal doc-follow smoke surfaced it. → **Rule 6.**
3. **Manifest placement friction (2.4).** `dots.ts` first landed in `web/src/content/` (the Vite import boundary) before code-review moved it to repo-root `content/` + a build-step. Minor, resolved; noted so the next "curated source-of-truth manifest" goes to repo-root `content/` + a generator from the start (like the allowlist).
