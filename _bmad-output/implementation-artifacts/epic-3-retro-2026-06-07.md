## What went well

- **Hands-off execution held (Josh's headline):** all 6 stories ran end-to-end; the only pauses were these end-of-epic gates. Josh's verbatim: *"Went well — proceed to Epic 4."*
- **The sonnet-dev / opus-QA+CR / lead-smoke ladder caught real defects at every rung the prior rung missed** — the split earned its keep again, and the OPUS QA tier was the standout this epic:
  - QA caught **three genuine test holes**: a false-positive AC5 assertion (3.2), an env-test that exercised a copy not the real module (3.3), and — the biggest — a **headline resilience e2e that was silently skipping** (3.4). QA didn't just flag these; it built the `serve-with-api.mjs` prod-faithful proxy harness so the JS-off path genuinely runs against real Postgres, and backstopped the vacuous tests with mutation-verified scoped assertions.
  - Code-review caught **3 MED** the dev passed — notably the `noValidate` leaking into the SSR'd form (3.4), which would have silently broken JS-off native validation (the resilience baseline).
  - The **lead smoke caught what the pipeline missed**: the receipt-copy exclamation (3.3), a voice-rule violation in server copy.
- **Epic-2 action items ALL carried through:** A1/A2 (Rules 5/6) were codified in the Epic-2 retro; **A3** (api port-robust / EADDRINUSE) was pulled forward and resolved early in Story 3.0; **A4** (the unreferenced React chunk / 0-JS re-verify) was resolved in Story 3.4 (the first island; the chunk is now legitimately used, non-island routes stay 0-JS).
- **NFR-1 evolved deliberately and stayed measurable:** three sanctioned client-JS carve-outs landed cleanly, each with an updated build-output assertion and a held JS-off baseline — the `/speaking` copy script (3.2, vanilla, sub-1KB), the `/invite` React island (3.4), and the home `/` island (3.5). The React runtime is provably isolated to `/` + `/invite/`; every other route stayed 0-executable-JS.
- **Credibility floor held (no fabrication):** every unconfirmed talk title/abstract, audience figure, testimonial, logo, bio, channel handle, and curated-media URL is `[OPEN]`/`[ASSUMPTION]` in *visible* text. Zero invented facts shipped.
- **System-of-record discipline:** Postgres-first persistence with env-gated email means a mail failure never loses an inquiry (`mail_status='failed'`), proven against the real DB with a forced mail-fail integration test; `RESEND_API_KEY` unset ⇒ `'skipped'` so the gate needs no live email (Rule 4).
- **Determinism + security held:** byte-stable builds throughout; `api/.env` (DB URL) gitignored and never staged; no secret reaches the client (NFR-5).

## What could be better

1. **A cross-service e2e silently skipped (3.4).** The JS-off resilience test — the story's #1 guarantee — never executed (`astro preview` doesn't proxy `/api`; `DATABASE_URL` unset → `test.skip()`), masked by "1 skipped." Only QA's proxy harness made it real. → **Rule 7.**
2. **Two vacuous/false-positive tests survived to QA (3.2, 3.3).** A whole-document `toContain` (satisfied by the JSON-LD) and an inline-copy schema test both passed while the real behavior could regress. → **Rule 8.**
3. **Orchestration nit (3.0):** the code-review agent kicked off a background gate run and yielded, leaving its Review Findings unwritten; the lead finalized it. Mitigated mid-epic by adding "finish the review in THIS run; run gates synchronously, do NOT background-and-yield" to every subsequent code-review spawn prompt — held for 3.1–3.5. (Spawn-prompt fix, not a project rule.)
4. **Voice discipline extends to server copy (3.3).** The no-exclamation rule was applied to page copy but the API receipt string slipped through until the smoke. Minor; folded into the per-story "no exclamation marks" checks going forward.
