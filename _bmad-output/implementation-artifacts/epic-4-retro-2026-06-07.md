Each tier added value the others couldn't.
- **Rule 7 (prove-the-e2e-executes) paid off and got stronger.** The `/api/guide` SSE e2e (4.3) and the Guide-panel e2e (4.4) were both proven to run (0 skipped) against the real endpoint via the `serve-with-api` harness — and QA *improved the harness* to always-start the API so the guide e2e runs even in a no-DB CI (it would have 502'd silently before). The retro A3 commitment was met directly.
- **Rules 7 & 8 (from Epic 3) were applied immediately and held.** Real-module + scoped assertions, mutation-verified throughout; the integration e2e proven-to-execute. The new contracts (`GuideQuery`, `CitationEvent {route,label}`) were finalized at their first consumer (retro A5 / deferred [1.1] resolved).
- **The credibility floor self-corrected within the epic.** After three fabrications in 4.1, the lead baked an enumerated fabrication-class guardrail into the 4.2 story — and 4.2 shipped **0 fabrications**. The fix worked, and it's now Rule 9.
- **Determinism + key-free static surface held.** The KB index is byte-deterministic (own sorted corpus + explicit ids, not Orama's internal state — research-driven); `web/dist` byte-stable; the LLM key resolves from IMDSv2/env at runtime and never reaches the client (NFR-5).
- **The real-runtime lead smokes earned their keep.** The 4.3 smoke hit the REAL VM LLM (not the stub) and proved a live grounded+cited answer + true fail-closed + injection resistance. The 4.4 smoke drove a REAL browser (chrome-devtools) through the full UX — pill → non-modal panel → starter chip → cited answer → follow a citation → page routes to `/work/loandemo/` with the conversation preserved.

## What could be better

1. **LLM-authored content fabrication was pervasive until guardrails were explicit (4.1).** Three distinct fabrications shipped from the dev stage and were caught only across QA + code-review + smoke (each catching a *different* one; narrow per-incident regression tests missed the next instance). → **Rule 9** (explicit fabrication-class guardrails in the story + a broad credibility audit, not spot tests).
2. **A hung dev stage that "looked done" hid unasserted guarantees (4.4).** The dev hung on its final gate; the gate was green, but its e2e *named* focus-not-trapped + NFR-2 per-message without *asserting* them, and a skip-link dangled. Only verifying fresh surfaced them. → **Rule 10** (a hung/interrupted stage is verified fresh, never assumed complete).
3. **The synchronous-completion directive was on code-review but not QA (4.2).** The QA agent background-and-yielded — the exact Epic-3 anti-pattern, recurring because the directive wasn't uniform across spawns. → **Rule 11** (the directive goes on ALL spawned stages).
4. **Threshold calibration is a known open tuning question (4.3, LOW).** The 0.5 retrieval threshold lets natural-language off-topic queries reach the model (which declines gracefully, grounded — no fabrication), so the "no model call" guarantee only fires for truly-zero retrieval. Deferred to NFR-7 telemetry-driven tuning — the documented trigger.
