## 2026-06-03 · IA + navigation model

**Two-layer IA** (reconciles cinematic narrative + crawlable fallback + agent routing):
- **Narrative layer** — `/` home Scene Arc: discrete, scrolled Scenes; calm hero first, the wow builds.

## 2026-06-03 · Advocate Agent — form factor

- **Form factor (Josh): floating, bottom-anchored, NON-MODAL panel.** Expands up from the persistent bottom-right *"Ask my Advocate"* pill (consistent with the home wireframe). The **page stays fully interactive** (no scrim, no focus trap); the agent floats over the bottom; **citations navigate the page behind while the conversation persists.** Desktop = ~400px floating card bottom-right (max ~65vh; one **soft shadow — the sole elevated surface** in an otherwise flat/hairline system); minimize-to-pill. Mobile = **partial bottom sheet** (~55–65vh) with the page visible/scrollable above.
- **Rationale:** serves the cite → read → keep-the-thread loop without blocking the page (beats modal); lighter/more ambient than a docked side panel (Josh's preference). Side panel was the acceptable fallback; floating chosen.
- **Trade-off (noted):** overlays/covers bottom content while open → mitigated by minimize + bottom-right placement.
- **Elevation decision:** the agent panel is the **single elevated surface** site-wide (justifies one restrained soft shadow token in DESIGN.md; everything else stays flat/hairline).
- **S1 scope:** grounded, cited Q&A · routing to Mirror routes · honest "not documented" (no model call below threshold) · designed per-message thinking state · suggested starter prompts. **S2 (not now):** intent re-curation, depth dial, director's mode.
