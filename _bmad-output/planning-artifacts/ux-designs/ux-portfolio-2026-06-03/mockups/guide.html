Accessibility floor

Feeds EXPERIENCE.md → Accessibility Floor (NFR-2).

  • role="dialog", NON-modal (aria-modal="false"). Focus moves to the panel on open but is NOT trapped — the page stays usable.
  • Transcript is role="log" + aria-live="polite", batched per message, never per token.
  • Thinking announced once per message via a role="status" / aria-live="polite" region.
  • Real <button> elements for the pill, starters, send, minimize, and close — not clickable divs.
  • Fully keyboard-operable; visible :focus-visible ring (navy) on every control.
  • Esc minimizes to the pill (does not destroy the thread).
  • The input is labeled (<label> bound to the field).
  • Citations are real links to Mirror routes; navigating them never closes the conversation.

Self-contained · inline CSS only · Source Serif 4 via Google Fonts <link> · no JavaScript · no images (avatar = a navy monogram in a hairline circle). The thinking state and progress sweep are rendered statically as designed surfaces, not spinners. Governs DESIGN.md → Components (Advocate Agent panel) + Elevation; EXPERIENCE.md → Component Patterns (Advocate Agent) + State Patterns + Accessibility Floor. The spines win on conflict.
