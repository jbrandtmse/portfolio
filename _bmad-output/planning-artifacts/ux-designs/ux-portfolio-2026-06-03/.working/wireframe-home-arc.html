Wireframe · Home Scene Arc (/) · low-fidelity / structural

One scrolled page of discrete Scenes — validating the IA + the scroll-native navigation model.

This is a structural wireframe, not a polished mock: hairline boxes, gray placeholders, real short labels. It shows the Stage-1 scene order, the persistent scene-rail (progress + jump + the FR-2 Skip affordance) on desktop and its mobile collapse (top progress bar + "Jump to section" menu), the hero fork (Explore vs book a talk), the persistent Advocate Agent entry, and the static fallback footer to every Mirror route. Identity (cream / ink / navy / hairlines, Source Serif 4 headings) is applied lightly so it reads as ours but stays structural.

Annotation legend — flow + interaction notes (navy = our annotations)

1
THE FORK (FR-1): hero offers two paths — Explore (enter the arc) vs I'm here to book a talk → jumps to /speaking, bypassing chat + the cinematic layer (protects organizer counter-metric).
2
SCENE-RAIL (FR-2): persistent right-edge rail — scene list + progress indicator (current highlighted) + an always-visible Skip / jump affordance. This IS the skip/progress requirement.
3
"One click in →": each teaser scene deep-links to its Mirror route (/timeline, /work/loandemo, /glass-box). The arc teases; the route holds the full content.
4
ADVOCATE AGENT entry: persistent docked "Ask my Advocate" (bottom-right desktop / button mobile). Agent overlay — form factor TBD (next pass). Panel NOT designed here.
5
SPEAKER SURFACE: the organizer deep-link target — reel + signature-talk list + copy-paste bio. Also lives at /speaking (where the fork jumps).
6
STATIC FALLBACK FOOTER: links to every Mirror route. JS-off / screen-reader fallback; reaches 100% of content. Mobile rail collapses to top bar + Jump menu.
