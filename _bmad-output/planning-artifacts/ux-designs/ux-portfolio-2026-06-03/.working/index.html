Josh Brandt — Portfolio Hero, four directions

Four complete visual personalities for the hero of a personal portfolio that demonstrates rather than describes — built in the open as a BMAD project, so the site is its own proof. All four are editorial-serif-led, calm and credible, with generous whitespace and a restrained palette. Each shows the hero in a desktop frame and a phone frame, plus the Advocate Agent panel and its designed thinking state.

Positioning: Seasoned, Not Stuck. · Two light, two dark · self-contained HTML, no JavaScript, no network requests · system fonts only.

The four directions

01GalleryLight

Austere museum wall — maximal whitespace, very large light-weight serif, hairline rules, a single oxblood accent. Lowest density; the wow is the restraint.

02LiteraryLight
