Typography specimens · editorial serifs

One voice, five faces.

The same real content, set five ways on the locked portfolio palette — warm cream paper #F6F0E6, near-black ink #211B14, Prussian-navy accent #1E3A5F. Four specimens load their true web font; one is a pure system-serif baseline with zero font payload. The page chrome below (labels, weight chips, payload estimates) stays in a quiet sans so it never competes with the face you are judging. Payload figures are approximate latin-subset woff2 for the loaded weights, for weighing against the perf budget.
