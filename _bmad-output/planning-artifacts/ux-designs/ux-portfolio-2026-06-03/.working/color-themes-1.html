Visual Identity · Color Themes · Pass 1

Warm, structured, editorial Gallery — accent options

One consistent warm base across all six: warm ivory paper, warm espresso ink, warm hairline rules, a faint drafting grid. What changes per option is the single restrained accent (and its deeper hover) plus the emotional register it lends. Each card shows the full semantic token set with live hex, then the same hero snippet rendered on the actual paper so you can judge ink, secondary, hairline, grid, and accent together. Light mode only — no dark variants here.

Shared base — surface-base #F6F0E6 · surface-raised #FBF7EF · ink-primary #211B14 (15.04:1) · ink-secondary #6B5D4A (5.63:1) · border-hairline #D8CAB3 · grid-line #ECE3D3 · WCAG 2.1 AA
